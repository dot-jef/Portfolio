# Jeferson Esteron - Portfolio

Personal portfolio website for Jeferson Esteron, an aspiring web engineer and
BSIT graduate based in the Philippines.

The site presents my background, technical skills, current learning goals, and
selected web development projects. I am currently looking for a job while
improving my skills through hands-on projects with the help of AI.

## Built with

- HTML
- CSS
- JavaScript
- Google Fonts: Space Grotesk and DM Mono

## Highlights

- Responsive single-page portfolio layout
- Hero section with introduction and current focus
- About section covering education, skills, and interests
- Project showcase with repository links
- Contact section with GitHub, LinkedIn, and email links
- Mobile navigation menu
- Scroll-based active navigation and reveal animations

## Featured projects

- [Sari-Sari Store Management System](https://github.com/dot-jef/Sari-Sari-Store)
  - Laravel, PHP, and JavaScript system for managing store products and sales.
- [Book Library](https://github.com/dot-jef/Book-Library)
  - Book search application using the Open Library API.

## Run locally

This is a static website and does not require a build step or package
installation.

1. Clone or download this repository.
2. Open `index.html` in a browser.

For a better development experience, serve the project with any local static
file server and open the provided local URL.
